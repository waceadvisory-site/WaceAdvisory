# Wace Advisory

Professional website for Wace Advisory - Expert Tax Preparation and Financial Advisory Services in Miri, Sarawak, Malaysia.

## 🌟 Features

- **4 Pages**: Home, About Us, Services, Contact Us
- **Responsive Design**: Mobile-friendly with hamburger menu navigation
- **WhatsApp Integration**: Direct contact via WhatsApp chatbot
- **Modern UI**: Built with Tailwind CSS and Material Symbols
- **Professional Accreditations**: MIA and ACCA member badges

## 📁 Project Structure

```
wayce/
├── index.html          # Homepage with hero section and services overview
├── about.html          # Company history, values, team profiles, accreditations
├── services.html       # Detailed service offerings (6 service cards)
├── contact.html        # Office location, WhatsApp contact, Google Maps
├── Image/              # Image assets folder
│   ├── PrimaryLogo.png
│   ├── SecondaryLogo.png
│   ├── Wace_ProfilePic.jpg.jpeg
│   └── WEBICO.ico
└── README.md           # Project documentation
```

## 🎨 Technologies Used

- **HTML5**: Semantic markup
- **Tailwind CSS**: Utility-first CSS framework (CDN)

- **Google Fonts**: Manrope font family
